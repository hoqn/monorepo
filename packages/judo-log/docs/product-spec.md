# 유도 복습 앱 기획·화면 설계서
*(한국어 용어 기준 · 일본어는 보조 표기)*

## 1. 한 줄 정의

주 1~2회밖에 도장에 못 가는 직장인이, **출퇴근길에 머리로 유도를 계속 굴리게 만드는 앱.**

---

## 2. 문제와 설계 전제

### 진짜 문제
입문자가 기술을 못 익히는 이유는 재능이 아니라 **간격**이다. 화요일에 배운 밭다리후리기를 다음 화요일에 다시 만나면, 그 사이 6일 동안 기억이 다 새어나간 상태로 시작한다. 매번 0에서 다시 출발하니 1년을 다녀도 진도가 안 나간다.

몸으로 하는 연습은 도장에서만 가능하다. 하지만 **기억 유지와 상황 판단은 머리로도 된다.** 그 빈틈을 메우는 게 이 앱의 전부다.

### 사용 환경 전제 (출퇴근길)

| 조건 | 설계에 주는 제약 |
|---|---|
| 지하철·버스 안 | **무음 전제.** 영상은 자막 필수, 소리 없이도 100% 이해돼야 함 |
| 한 손, 세로 화면 | 모든 주요 조작은 엄지 닿는 하단 1/3에 배치 |
| 몸을 못 움직임 | 신체 동작 요구 금지. 대신 **심상(이미지 트레이닝)** 유도 |
| 5~15분, 언제든 끊김 | 세션 자동 저장. "내릴 때 끄면 그 자리부터" |
| 데이터·지하 구간 | 오프라인 우선. 텍스트/이미지 캐싱, 영상은 다운로드 방식 |

## 3. 용어 정책 (이 앱의 정체성)

**한국어 명칭이 주(主), 일본어는 괄호 보조.**

```
밭다리후리기
大外刈 · 오소토가리          ← 작게, 회색으로
```

### 왜 이게 중요한가
1. **한국어 명칭은 그 자체로 설명이다.** "밭다리후리기"는 이름만 들어도 바깥쪽 다리를 후린다는 게 읽힌다. "오소토가리"는 외워야만 아는 소리 덩어리다. 입문자에게는 학습 부담이 절반으로 준다.
2. **묶어서 이해된다.** 밭다리후리기 / 안다리후리기 / 발뒤축후리기 / 안뒤축후리기가 나란히 놓이면 안-밖, 다리-뒤축의 격자가 저절로 보인다. 일본어로는 이 구조가 안 드러난다.
3. 씨름 용어와 이어진다. 밭다리·안다리는 한국인에게 이미 익숙한 몸의 언어다.

### 그래도 일본어를 버리면 안 되는 이유
도장에서 사범님이 "오소토!"라고 외치는 순간을 못 알아들으면 앱이 현실과 따로 논다. 국제 대회 자료, 유튜브 강의도 전부 일본어 명칭 기준이다. **보조 표기는 필수.**

### 별칭(alias) 필드가 반드시 필요하다
공식 국내 용어와 현장에서 실제로 부르는 말이 다른 경우가 흔하다. 예를 들어 우치마타는 공식 명칭이 **허벅다리걸기**지만, 도장에서는 **허벅다리후리기**로 더 많이 불린다. 검색이 한쪽만 물면 사용자는 "내 기술이 앱에 없네" 하고 이탈한다.

→ 검색은 **한국어 정식명 + 별칭 + 일본어 발음 + 로마자** 전부를 매칭해야 한다.
`"우치마타" / "허벅다리" / "uchimata"` → 모두 같은 카드로.

### 표기 규칙
- 카드·목록·제목: **한국어만** (일본어까지 넣으면 좁은 화면이 지저분해짐)
- 기술 상세 화면 상단: 한국어 크게 + 한자·일본어 작게
- 검색: 양쪽 다 입력 가능, 결과는 한국어로 표시
- 심판 용어: **한국어 우선** (시작 / 그쳐 / 한판). 실제 국내 시합에서 한국어로 선언된다.

## 4. 핵심 메커니즘: 씨앗 → 카드 → 복습

앱이 죽는 가장 흔한 원인은 **"기록이 안 쌓여서"** 다. 도장에서 땀 흘리고 나와서 긴 회고를 쓰는 사람은 없다. 그래서 입력을 두 단계로 쪼갠다.

```
[도장, 30초]        [출퇴근길, 5~10분]      [출퇴근길, 3~5분]
  씨앗 심기     →      카드로 키우기      →      복습하기
 오늘 뭐 배웠나       기억 짜내서 정리         밀린 카드 처리
 태그만 톡톡          = 이미 복습 1회차        = 간격 반복
```

여기서 중요한 발상: **"정리하는 행위 자체가 첫 번째 복습"** 이다. 도장에서 대충 찍어둔 태그를 보고 퇴근길에 "그게 뭐였더라, 발을 어디에 걸었지" 하고 짜내는 과정이 인출 연습(retrieval practice)이라 기억에 가장 강하게 박힌다. 이걸 사용자에게도 설명해줘야 "귀찮은 정리 작업"이 아니라 "훈련"으로 받아들인다.

## 5. 카드 유형

유도 기술을 영어 단어처럼 앞뒤 뒤집는 플래시카드로 만들면 실패한다. 절차 기억이라 성격이 다르다. 4가지로 나눈다.

**① 명칭 카드** — 순수 암기 (여기서만 일본어를 정면으로 다룸)
> 앞: "바깥쪽에서 상대 다리를 후려 넘기는 기술은?"
> 뒤: **밭다리후리기** (大外刈 · 오소토가리)

**② 순서 카드** — 절차 회상
> "밭다리후리기를 4단계로 떠올려봐"
> → 답 보기 전에 머릿속으로 나열 → 뒤집어서 확인
> 뒤: 1. 오른손으로 당겨 상대 체중을 오른발에 2. 왼발을 상대 오른발 옆에 3. 오른다리를 크게 후려 4. 상체를 눌러 넘김

**③ 상황 카드** — 판단 훈련 (제일 실전에 가까움)
> "상대가 오른팔로 내 깃을 세게 밀어낼 때, 그 힘을 이용해 들어갈 수 있는 기술은?"
> 뒤: 미는 힘을 그대로 뒤로 → **안다리후리기** 또는 **빗당겨치기**

**④ 심상 카드** — 이미지 트레이닝
> "눈 감고 밭다리후리기를 3회 걸어봐. 상대 발이 뜨는 순간까지."
> 타이머 30초 → 끝나면 "선명했나?" 3단계 자기평가
> ※ 실제 선수 훈련에 쓰이는 검증된 방법이라는 안내 문구 필요

카드 생성은 **반자동**이 좋다. 기술을 태그하면 앱이 ①②④를 기본 DB에서 자동 생성하고, ③과 개인 메모는 사용자가 채운다.

## 6. 정보 구조

```
기술(Technique)          ← 기본 내장 DB + 내 메모가 붙는 단위
 ├ 한국어명(주)          "밭다리후리기"
 ├ 별칭[]                "밭다리", "바깥다리후리기"
 ├ 일본어                大外刈 / 오소토가리 / osoto-gari
 ├ 분류                  메치기 > 발기술
 ├ 표준 단계, 핵심 포인트, 흔한 실수
 └ [내 것] 메모, 숙련도, 첫 배운 날, 관련 세션들

세션(Session)            ← 도장 다녀온 기록 1회
 ├ 날짜, 배운 기술 태그[], 대련(랜도리) 여부
 └ 한 줄 소감 / 음성 메모 원본

카드(Card)               ← 복습의 최소 단위
 ├ 유형(①~④), 소속 기술, 앞/뒤 내용
 └ 다음 복습일, 간격, 연속 정답 수

복습로그(Review)         ← 카드 하나를 본 기록
 └ 날짜, 자기평가(까먹음/애매/기억남)
```

**핵심**: 기술을 태그하며 세션을 쌓으면, 그게 자동으로 **"나만의 기술 서랍"** 이 된다. 처음에 고민했던 "기술 노트"와 "백과" 방향이 여기서 결과물로 흡수된다. 별도 기능을 만들 필요가 없다.

│         1회 연습        │
│                        │
│  ─ 아직 안 배운 기술 ─   │
│  ○ 업어치기            │
│  ○ 허리후리기          │
│                        │
└────────────────────────┘
```

- 이게 곧 **개인 백과**다. 시간이 지나면 "내가 이만큼 쌓았구나"가 눈에 보이는 성장 지표가 된다.
- 분류 탭도 한국어 기준: 손기술 / 허리기술 / 발기술 / 굳히기. 일본어 분류(테와자·고시와자·아시와자)는 상세에서만.
- 숙련도 막대 = 연습 횟수 + 복습 성적. 정확할 필요 없고, **줄어들 수 있어야** 한다 (한동안 안 하면 흐려짐 → 다시 복습하게 만드는 동기).

### 화면 6. 기술 상세

```
┌────────────────────────┐

│  밭다리후리기           │

│                        │

- 여기가 일본어 명칭을 정면으로 보여주는 유일한 자리. 한국어 → 한자 → 발음 → 로마자 순으로 크기를 줄여가며 배치.
- **"이력" 탭이 이 앱의 감정적 핵심.** 3개월 전 메모("발이 꼬임")와 지금 메모("타이밍이 조금 늦음")를 나란히 보면 성장이 체감된다. 이게 재방문 이유가 된다.

## 8. 복습 간격 알고리즘

기본은 간격 반복이되, **유도 수련 주기에 맞춰 변형**한다.

```
기본 간격    1일 → 3일 → 7일 → 14일 → 30일
「까먹음」   간격 초기화 (1일로)
「애매하다」 간격 유지 (같은 간격 한 번 더)
「기억남」   다음 단계로
```

**수련일 보정 (중요):** 다음 수련 1~2일 전이면, 그날 배울 가능성이 높은 기술 카드를 **간격 무시하고 앞당겨서** 큐에 넣는다. 목적이 시험 통과가 아니라 **매트 위에서의 수행**이기 때문에, 실전 직전 복습이 가장 가치가 높다.

**하루 상한**: 20장. 지하철에서 50장 밀려 있으면 그냥 앱을 안 연다. 밀린 게 많으면 "오늘은 중요한 것 20장만"으로 잘라준다.

## 9. 콜드 스타트 대응

최대 리스크는 **"기록이 없으면 복습할 게 없어서 첫 주에 이탈"** 이다.

해결책: 가입 시 수련 경력(예: 2개월차)을 입력받고, **입문자 공통 카드 30장을 미리 채워준다.**
- 낙법 4종: 후방낙법 / 측방낙법 / 전방낙법 / 전방회전낙법
- 예법, 도복 매는 법
- 심판 용어: 시작 / 그쳐 / 그만 / 한판 / 절반 / 누르기 / 풀려 / 지도
- 기본 기술 5~6개: 밭다리후리기, 안다리후리기, 업어치기, 허리띄기, 곁누르기

이러면 설치 당일부터 복습할 게 있고, 자기 기록이 쌓이면서 자연스럽게 개인화된다.

## 10. MVP 범위

**v1에 넣을 것**
1. 빠른 기록 (기술 태그 + 음성 메모)
2. 정리하기 → 카드 생성
3. 복습 세션 (카드 4종 + 3단계 평가)
4. 내 기술 서랍 + 기술 상세
5. 기본 기술 DB (한국어 정식명 + 별칭 + 일본어)

**v1에서 뺄 것**
- ❌ 영상 — 저작권이 골치 아프고, 무음 환경에선 가치가 낮다. v1은 텍스트 + 도해로 충분
- ❌ 소셜·랭킹 — 혼자 쓰는 도구로 먼저 완성
- ❌ 상세 통계 대시보드 — 데이터 쌓인 뒤에
- ❌ 수련 전 브리핑 — 좋은 기능이지만 v1.1로
- ❌ 로그인·서버 — 로컬 저장으로 시작

**성공 판정 기준**: 본인이 2개월 동안 계속 쓰는가. 안 쓰면 남도 안 쓴다.

## 11. 남은 리스크

| 리스크 | 대응 |
|---|---|
| 도장에서 기록 자체를 안 함 | 30초 설계 + 수련 종료 시간대 푸시 1회 |
| 정리 단계가 귀찮아서 밀림 | 정리 = 복습이라고 계속 알려주기. 예상 시간 표시 |
| 기술 이름을 몰라 태그 못 함 | 자유 텍스트 임시 저장 → 나중에 도해 보고 매칭 |
| 공식 용어와 도장 용어가 달라 검색 실패 | 별칭 필드 필수. 사용자가 별칭을 직접 추가할 수 있게 |
| 기술 정보가 틀림 | 표준 설명은 공신력 있는 출처 기반으로만. 내 메모와 시각적으로 확실히 구분 |
| 머리로만 하다 실제 실력 착각 | "이건 몸 연습을 대체하지 않는다"를 온보딩에 명시 |
